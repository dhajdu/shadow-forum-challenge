Ways of working

Rules for the build

One branch per PR (feat/*); small, reviewable diffs.
Merge to main → Vercel deploys prod. No CLI deploys.
Every PR gets a preview URL + green CI before merge.
New env var → added to .env.local and Vercel same PR.
Never commit .env* or secrets.
RLS on by default; verify data isolation per feature.

Open decisions to confirm before PR #6: which WHOOP metric ranks the race · currency of "M" · where the kitty goes · who coaches whom.
